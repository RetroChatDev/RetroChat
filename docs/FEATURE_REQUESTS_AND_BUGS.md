# Feature Requests & Bug Reports

Help shape RetroChat.

## Feature requests

Open **Settings → Feature Requests** (also available from the main menu) to:
- Browse open ideas from the community.
- Upvote ideas you want to see built.
- Submit your own idea with a title and description.

Popular ideas are reviewed regularly and status (Planned, In Progress, Shipped, Declined) is posted on each entry.

## Bug reports

Tap the **Report a bug** button in **Settings → Help** or the bug icon in the main menu. The bug report modal collects:
- A short description of what happened.
- What you were doing when it happened.
- Optional screenshot.
- App version and device (attached automatically).

Bug reports go straight to the RetroChat engineering team. If we need more info we'll reach out via your account's notification inbox.

## Before you file

- Check the [Status Page](STATUS_PAGE.md) for known outages.
- Note whether the issue happens on iOS app, Android PWA, or desktop — that speeds up triage.
- For wallet or Token Studio issues, include whether you use Phantom or the in-app wallet (never paste recovery phrases).
