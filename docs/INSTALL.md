# Install RetroChat

RetroChat is available as a native **iOS** app and as an installable **PWA** on desktop and Android browsers.

## iOS

1. Open the [App Store listing](https://apps.apple.com/us/app/retro-chat-on-sol/id6766412897), or search for **RetroChat**.
2. Tap **Get**.
3. Launch the app and sign in.

## Android

A dedicated Google Play listing is not the primary install path today. On Android:

1. Open [retrochat.io](https://retrochat.io) in **Chrome**.
2. Tap the browser menu and choose **Install app** or **Add to Home Screen**.
3. Launch RetroChat from your home screen.

## PWA (desktop and mobile web)

The PWA runs in a standalone window with the same features as the browser version, minus some native-only integrations (for example the in-app Browser and certain push setups).

### Desktop (Chrome, Edge, Brave, Arc)

1. Visit [retrochat.io](https://retrochat.io) in your browser.
2. Click the **Install** icon in the address bar, or open the browser menu and choose **Install RetroChat**.
3. Launch RetroChat from your dock, taskbar, or applications folder.

### Safari on macOS

1. Visit RetroChat in Safari.
2. Choose **File → Add to Dock**.

### iPhone / iPad (Safari)

1. Visit RetroChat in Safari.
2. Tap the **Share** button and choose **Add to Home Screen**.

You can also install the native iOS app from the App Store for the fullest mobile experience.

## Sign in from the install prompt

RetroChat's `/install` page walks you through installation on any device and links to the App Store when available.

## Uninstalling

- **iOS**: long-press the app icon and choose **Delete App**.
- **PWA**: from the installed app window, open the menu and choose **Uninstall RetroChat**, or remove the home-screen icon on mobile.
