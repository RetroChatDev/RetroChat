# Internet Explorer (in-app browser)

Internet Explorer is RetroChat's built-in web browser. It keeps you inside RetroChat when opening links, wallet dApps, or research pages.

## Tabs

- Tap **+** to open a new tab.
- Long-press a tab to close it.
- Tabs persist across sessions until you close them.

## Bookmarks

- Tap the star icon in the address bar to bookmark the current page.
- Open the bookmarks drawer from the toolbar to jump back to a saved page.

## Address bar

- Type a URL or a search query. Non-URL input runs a web search.
- **Refresh** and **Share** live next to the address bar.
- Tap the up-arrow icon to open the current page in your device's default browser.

## When to use it

- Opening links posted in chat rooms without losing your place.
- Connecting to Solana dApps that request wallet approval from RetroChat.
- Reading community-shared articles in a distraction-free tab.
