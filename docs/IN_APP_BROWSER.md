# In-App Browser

On the native iOS and Android apps, RetroChat includes a built-in **Browser** so you can open links and Solana sites without leaving the app. On desktop and mobile web, links open in your system browser instead.

## Opening the Browser

From the native app shortcut or wallpaper browser tools, open **Browser**. You can also open supported site shortcuts from chat.

## Tabs

- Tap **+** to open a new tab.
- Close tabs from the tab list when you are done.
- Tabs can persist across sessions until you close them.

## Bookmarks

- Bookmark the current page from the toolbar.
- Open the bookmarks list to jump back to a saved page.

## Address bar

- Type a URL or a search query. Non-URL input runs a web search.
- Refresh and share live next to the address bar.
- Open the current page in your device's default browser when you want to leave RetroChat.

## When to use it

- Opening links posted in chat rooms without losing your place.
- Visiting Solana sites that request wallet approval from RetroChat.
- Reading community-shared articles in a focused tab.
