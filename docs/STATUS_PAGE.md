# Status Page

The public status page shows the live health of RetroChat's services so you can tell whether an issue is on your side or ours.

## What you'll see

- Overall system status (operational, degraded, or outage).
- Per-service status for core components — for example chat, wallet, live streaming, media uploads, Retro TV, and notifications.
- Last-updated time and a refresh control.

The page reflects **current** health. It does not currently include a full public incident history archive or email/SMS subscriptions.

## How to reach it

- On the web: open [retrochat.io/status](https://retrochat.io/status), or use the **Status** link in the public footer.
- From About and related public pages that link to Status.

## When something looks wrong

1. Refresh the status page.
2. Check your connection and try another network if needed.
3. If Status shows degraded or outage for the feature you need, wait for recovery — duplicate bug reports are optional until service returns.
4. If Status shows operational but the app still fails, file a bug from **Settings → Help** (see [Feature Requests & Bug Reports](FEATURE_REQUESTS_AND_BUGS.md)).
